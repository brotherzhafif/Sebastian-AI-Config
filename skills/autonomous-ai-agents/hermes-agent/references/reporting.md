### Server Health and Status Reporting
- **Command Trigger**: "cek status", "status server", or similar.
- **Reporting Format**:
  1. **🖥️ SERVER HEALTH**: RAM (Used/Total/Available), Uptime, Storage (Used/Total/%), Load Average.
  2. **🤖 AI STATUS (Sebastian)**: Token usage (Session/Total), Memory entries, Active skills count, Active processes, System Latency.
- **Data Integrity**: Ensure all metrics are provided as precise numbers and the format is strictly maintained for readability.
