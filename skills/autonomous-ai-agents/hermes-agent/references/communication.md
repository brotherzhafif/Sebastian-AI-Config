# Task Execution & Communication Protocol

- **Verbosity:** Always prioritize silent execution. Do NOT output tool-retry logs, attempt counts, or meta-commentary in chat. Focus entirely on delivering the final result requested by Tuan Zhafif.
- **Reporting:** If a task fails, provide only the critical error info. If successful, provide just the output.
- **Interactivity:** If the user explicitly asks for status/logs, provide them in the format defined in the `reporting.md` reference.
